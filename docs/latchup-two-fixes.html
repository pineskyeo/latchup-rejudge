A 측정 그대로, 판정만 개선

장비가 하는 일은 한 줄도 바뀌지 않습니다. 같은 sweep, 같은 측정점, 같은 LUP 로그. 측정이 끝난 곡선에서 VT/VH를 고르는 규칙만 바꿉니다.

  1. 0

    기존: 처음 꺾이는 곳

    ΔV 부호가 처음 바뀌는 점이 VT, 다음 점이 VH. 1차 snapback(1.22 V)에 걸립니다. 이 snapback은 전류를 더 올리면 다시 전압이 오르므로 래치가 아닙니다.

  2. 1

    snapback 찾기

    꼭대기에서 max(50 mV, 3%×V) 넘게 떨어져야 snapback으로 셉니다. 그보다 작은 흔들림은 무시합니다. 이 곡선에서는 두 개가 나옵니다.

  3. 2

    깊이 비교

    깊이 = 꼭대기 − 골. 가장 깊은 것의 70% 이상인 snapback만 후보로 남깁니다. 1차(0.20 V)는 2차(0.48 V)의 70%인 0.34 V에 못 미쳐 빠집니다.

  4. 3

    결과

    후보 중 꼭대기 전압이 가장 높은 것을 고릅니다. 그 꼭대기가 VT, 그 골이 VH입니다. 1차 값은 VT1/VH1로 따로 남깁니다.

출력값 (위 곡선)의미
VT, VTI새 판정 trigger 전압·전류 (출력 이름은 기존과 같음)
VH, VHI새 판정 hold 전압·전류
VT1, VH1첫 번째 snapback (참고용)
NSNAP2찾은 snapback 수. 2 이상이면 이중 snapback
LVT, LVH같은 곡선에 기존 규칙을 적용한 값. 기존 데이터와 나란히 비교할 때 사용
  • 바이어스 파일에서 알고리즘 이름만 바꾸면 됩니다. 새 파라미터(DvAbs 0.05 / DvRel 0.03 / MainFrac 0.7)는 DEVICE 쪽 기본값이 있습니다.
  • 규칙은 latchup_rejudge.py --rule main과 같습니다. 이미 쌓인 LUP 로그는 스크립트로, 앞으로의 측정은 장비에서 같은 값이 나옵니다.
  • stub 테스트: 원본 latchup_supply_io와 장비 호출 순서가 완전히 같고, 샘플 곡선 11개에서 rejudge.py와 값이 같은 것을 확인했습니다. 실제 장비 컴파일은 아직입니다.

B 전원 인가형: 측정 방식 변경

래치업의 정의는 "트리거가 사라진 뒤에도 전원에서 큰 전류가 계속 흐르는 상태"입니다. 기존 조건은 전원이 0 V라 유지시킬 에너지원이 없습니다. 그래서 곡선 모양으로 추측할 수밖에 없습니다. B는 정의 그대로 잽니다.

  1. 1

    정상 전류

    전원에 VDD_max를 걸고 IO는 0 A. 이때 전원 전류가 I_nom. 판정 기준 thr = max(I_nom + 10 mA, 1.4 × I_nom) (JESD78 방식).

  2. 2

    트리거 넣고 빼기

    IO에 펄스(1 ms)를 넣고 IO 전압을 읽은 뒤, 0 A로 되돌리고 1 ms 기다려 I_DD를 잽니다. 펄스를 ×1.05씩 키우며 반복. 1차 snapback 크기의 펄스는 빼면 꺼지므로 I_DD가 돌아옵니다.

  3. 3

    래치 판정

    펄스를 뺀 뒤에도 I_DD > thr이면 래치. 그 펄스 동안의 IO 전압이 VT(LU_VT), 펄스 전류가 LU_IT.

  4. 4

    Hold 전압

    래치된 전원을 0.05 V씩 내립니다. I_DD가 정상으로 돌아가기 직전 전압이 VH(LU_VH). VH > VDD_max이면 전원만으로는 래치가 유지되지 않습니다.

  5. 5

    복구 확인

    전원을 0 V로 내렸다 다시 올려 I_DD가 thr 이하인지 봅니다. 돌아오면 STATUS 1, 아니면 2 (손상 의심).

왜 이 순서인가

  • 전원을 켜는 이유: 래치는 VDD→VSS 경로의 PNPN이 스스로 전류를 유지하는 현상입니다. 전원이 0 V면 유지될 수 없어서 "유지되는가"를 볼 수 없습니다.
  • 트리거를 빼는 이유: 넣고 있는 동안 흐르는 전류는 트리거 때문인지 래치 때문인지 구분이 안 됩니다. 빼고 남는 것만 래치입니다. 1차 snapback이 여기서 자동으로 걸러집니다.
  • VDD를 내리는 이유: 래치가 유지되는 최소 전원 전압을 찾아 VDD_max와 비교하려는 것입니다.
  • 마지막 전원 재인가: 래치 전류에 소자가 손상됐는지 확인합니다.

대신 바뀌는 것

  • VT는 같은 IO 핀 전압이지만 N-well이 VDD에 묶여 있어 값이 달라지고, 꼭대기가 아니라 래치를 남긴 펄스의 전압입니다.
  • VH는 IO 경로가 아닌 VDD 경로 SCR의 값입니다. 기존 VH(1.18 V)와 직접 비교할 수 없습니다.
  • 래치되면 전원 전류가 compliance(기본 0.1 A)까지 흐릅니다. compliance를 소자에 맞게 낮춰야 합니다.

어느 쪽을 쓰나

A를 쓸 때

지금 spec과 과거 데이터를 유지하면서 1차 snapback 오판정만 없애고 싶을 때. 바이어스 조건 변경 승인이 필요 없습니다.

B를 쓸 때

실사용 조건에서 래치가 걸리는지 자체를 보고 싶을 때. 별도 DOE 항목으로 추가하고 spec을 새로 정하는 것을 전제로 합니다.
